## 已知小问题

`real_5min_capture` binary 的 output 路径是 **hardcoded 为 `runs/2026-06-05_real_5min/`**,
不是按当前日期生成。所以**两次 5 min 跑的数据被 append 进了同一文件**:
- 第一次写 49650 行 + events + metadata
- 第二次 append 49800 行,events.jsonl 现在是 4 行(start1 + stop1 + start2 + stop2),
  metadata.json 还是第一次的
- **最终 `samples.ndjson` 是 99450 行 = 49650 + 49800**(v0.2 应该按日期生成目录)
